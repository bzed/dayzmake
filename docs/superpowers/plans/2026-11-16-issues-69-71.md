## Review Focus

1. `-d` with a value that would make the output unparsable (`-d x`, newline): rejected with a clear error, not written.
2. `-d ""` (empty): allowed, gives unindented output that still rapifies to the same bytes.
3. `img2paa -c` on a small image (≤128 px wide) or where LZO does not shrink a mipmap: file still valid, those mipmaps stored raw and unmarked.
4. `img2paa -c` with a non-DXT type (e.g. `argb8888` if supported): no LZO, no error (or a clear error; pick one and document it).
5. `cat -f` without a target (stdout): accepted and harmless.
